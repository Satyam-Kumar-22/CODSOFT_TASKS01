# CODSOFT Frontend Development Internship

This repository contains three tasks completed for the CODSOFT Frontend Development Internship.

## Task 1: Personal Portfolio Website
A responsive personal portfolio website showcasing profile information, skills, projects, resume, and contact form validation.

**Technologies:** HTML, CSS, JavaScript

## Task 2: To-Do List Application
A task management application with add, edit, delete, task completion, search, filters, and Local Storage.

**Technologies:** HTML, CSS, JavaScript

## Task 3: Expense Tracker
A personal finance application to record income and expenses, calculate the current balance, and manage transaction history.

**Technologies:** HTML, CSS, JavaScript, Local Storage

## How to Run
1. Open the required task folder.
2. Open its `index.html` file in a browser.
3. Alternatively, use the VS Code Live Server extension.
