# Personal Portfolio Website

A responsive personal portfolio website developed as part of the CODSOFT Frontend Development Internship – Task 1.

## About the Project
This website showcases my profile, technical skills, projects, resume, and contact information through a clean and responsive user interface.

## Features
- Personal introduction
- Technical skills section
- Projects showcase
- Resume section
- Contact form with JavaScript validation
- Responsive design

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Open the `Task-1-Portfolio` folder.
2. Open `index.html` in a web browser.
3. Alternatively, use the VS Code Live Server extension.
